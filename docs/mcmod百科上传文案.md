## 简介

成龙历险记模组是一个以《成龙历险记》中的十二符咒、黑影兵团和圣主为核心内容的冒险向模组。模组加入了十二枚具有不同能力的符咒、忍者面具、老爹的河豚、圣主宫殿结构、圣主 Boss、暗影兵团忍者以及若干角色实体。

玩家可以在探索、战斗、钓鱼、考古和击败生物的过程中获得符咒，并使用符咒获得速度、力量、治疗、隐身、变身、飞行、灵魂出窍、分身、激光和爆破等能力。模组还加入了可自然生成的圣主宫殿，宫殿中可遭遇圣主和黑影忍者，并获得高价值战利品。

## 主要内容

### 十二符咒

所有符咒均不可堆叠，多数符咒右键使用后会给予玩家对应的魔法效果。若玩家失去对应符咒，持续类符咒效果会被快速缩短。

| 符咒 | 主要能力 | 获取方式 |
| --- | --- | --- |
| 马符咒 | 定期清除负面效果并恢复生命值。 | 钓鱼时有概率替换钓鱼战利品。 |
| 牛符咒 | 大幅提高攻击伤害和击退能力。 | 猪灵堡垒战利品箱中概率获得。 |
| 兔符咒 | 大幅提高移动、飞行和水中移动能力。 | 海龟死亡掉落中概率获得。 |
| 蛇符咒 | 隐身，并让敌对生物失去仇恨。攻击后会短暂暴露。 | 远古城市战利品箱中概率获得。 |
| 狗符咒 | 受到伤害时生命值不会低于半颗心。 | 唤魔者掉落或驯服的狼死亡掉落中概率获得。 |
| 鸡符咒 | 漂浮升空，按住 Shift 可下降。与兔符咒组合时可高速飞行和悬停。 | 目前仅创造模式/命令获取。 |
| 猴符咒 | 可变身为多种生物，按住 Tab 加滚轮选择形态。 | 海底废墟考古战利品中概率获得。 |
| 虎符咒 | 分离善恶，生成携带装备的玩家分身；靠近分身后可重新融合。 | 下界要塞战利品箱中概率获得。 |
| 龙符咒 | 发射龙爆破，命中后爆炸。 | 击败圣主后掉落。 |
| 鼠符咒 | 发射光束，命中方块或生物后停止。 | 地牢、废弃矿井、要塞走廊/交叉口/图书馆箱子中概率获得。 |
| 猪符咒 | 从双眼射出激光，伤害并击退路径上的生物，也会破坏路径上的部分方块。 | 目前仅创造模式/命令获取。 |
| 羊符咒 | 灵魂出窍，身体留在原地，灵魂可自由探索；可追踪身体位置并返回身体。 | 末地城宝箱中概率获得。 |

### 变身

猴符咒可选择多种形态，包括鸡、牛、猪、马、狼、猫、悦灵、蝙蝠、鹦鹉、蜜蜂、鳕鱼、海豚、海龟、蝌蚪、青蛙、鱿鱼、美西螈、北极熊、骡、驴、狐狸、嗅探兽、羊驼、兔子、熊猫和河豚，也可以选择恢复原形。

### 黑影兵团

模组加入了忍者面具和暗影兵团忍者。

忍者面具是头盔类物品，装备后会获得“黑影将军的祝福”，并可操控暗影兵团忍者。面具会自动附带“魔法绑定”附魔，通常无法直接摘下；使用以粗制药水和鲑鱼酿造的“能够摘下黑影将军面具的药水”可解除面具。

默认快捷键：

- `X`：召唤黑影忍者
- `C`：撤下黑影忍者
- `B`：命令黑影兵团下跪

暗影兵团忍者拥有自定义模型和动画，会跟随并保护佩戴面具的玩家，也可以参与战斗、下跪待命或通过阴影突进接近目标。

### 圣主与圣主宫殿

圣主是模组加入的大型 Boss，拥有 500 点生命值、Boss 血条、近战攻击、龙息远程攻击和召唤黑影忍者的能力。圣主死亡后会掉落龙符咒。

圣主宫殿会在沙漠、恶地和风蚀恶地中生成。结构集使用随机扩散放置，间距为 12、分离距离为 6。宫殿包含多种建筑组件和奖励箱，奖励箱中可能出现矿物、钻石装备、附魔书、箭、火焰弹等战利品，并有 5% 概率出现忍者面具。

老爹的河豚可切换为“感应魔气模式”，用于在 5000 格范围内寻找最近的圣主宫殿；当玩家面向宫殿方向时，道具会发光提示。

### 老爹的河豚

老爹的河豚是耐久为 50 的战斗/探测道具，拥有两种模式：

- 攻击模式：发射 32 格射程的激光，对普通目标造成 8 点魔法伤害；对暗影兵团忍者造成处决级伤害。
- 感应魔气模式：扫描附近圣主宫殿，并显示大致方向和距离。

合成配方：

```text
金锭 金锭 金锭
钻石 河豚 钻石
黏液球 黏液球 黏液球
```

### 建筑构造器

模组加入了多种建筑构造器，可用于生成圣主宫殿相关建筑。右键空气可隔空放置，右键方块可在点击位置生成。包括承天殿、栖月宫、凌霄楼、听风阁、听雨亭、凌云台、映霞榭、回风廊、浮光舫、凤鸣阙、重华门、含香院、明德堂和听竹斋构造器。

### 其他实体

模组还加入了爱博、莫迪才和飞猪组合等实体，并提供对应刷怪蛋。飞猪组合属于敌对实体，爱博和莫迪才属于生物类实体。

## 配置

模组提供符咒战利品概率配置，范围为 `0.0` 到 `1.0`。默认概率包括：

- 马符咒钓鱼：10%
- 鼠符咒地牢、废弃矿井、要塞箱子：40%
- 猴符咒海底废墟考古：20%
- 牛符咒猪灵堡垒：40%
- 兔符咒海龟掉落：10%
- 狗符咒唤魔者/驯服的狼：5%
- 羊符咒末地城：40%
- 蛇符咒远古城市：20%
- 虎符咒下界要塞：40%
