# shadow_ninja.animation.json 说明

`shadow_ninja.animation.json` 是标准动画 JSON，格式本身不支持注释。
为了不引入非法字段、避免资源加载失败，注释说明单独放在这个文档里。

## 文件阅读方式

- `idle` / `walk`：循环基础动作，重点看身体重心和四肢摆动是否自然。
- `attack_*`：爆发型动作，通常分成蓄力、命中、收势三个阶段。
- `kneel`：固定姿态，主要用于过场或待命。
- `summon` / `dismiss`：功能动作，应该强调“起势”和“收势”，同时尽量顺滑地回到默认站姿。

## 骨骼职责约定

- `root.position`：整体重心位移，用来做前冲、下沉、回弹。
- `body.rotation` / `body.position`：胸腔和躯干主节奏，决定动作是否“有力”。
- `head.rotation`：补充视线方向，避免动作像木偶。
- `left_arm` / `right_arm`：大臂负责出招方向和轮廓。
- `left_forearm` / `right_forearm`：前臂负责收放感，让动作更完整。
- `left_leg` / `right_leg` 与 `shin` / `foot`：负责支撑和步态节奏。

## 本次优化重点

### shadow_ninja.summon

- 原版本主要只有头、身体和双臂三组旋转，`root.position` 全程为零，动作层次偏平。
- 现在改成了更明确的四段节奏：
- `0.00 - 0.18`：下沉蓄力，重心后收。
- `0.18 - 0.42`：抬身释放，身体和双臂向上回弹。
- `0.42 - 0.72`：余势减弱，保留一点动作残响。
- `0.72 - 1.20`：自然回到默认姿态。
- 新增了 `body.position`、`left_forearm`、`right_forearm`，让召唤动作不再只靠大臂摆动。

### shadow_ninja.dismiss

- 原版本末尾停在一个明显前倾姿态，若直接切回站立或待机，视觉上容易产生“弹回”。
- 现在改成“轻抬 -> 下压 -> 缓收 -> 归位”的流程：
- `0.00 - 0.24`：轻微抬身准备。
- `0.24 - 0.56`：明显向下压动作，作为遣散指令的主体节奏。
- `0.56 - 0.86`：收势，保留少量余动作。
- `0.86 - 1.20`：回归中性站姿，方便衔接其他动画。
- 同样补上了 `body.position` 和前臂关键帧，并移除了原先纯零占位的位移轨道写法。

## 后续如果还想继续优化

- 如果你希望战斗感更强，可以继续细化 `attack_left_punch`、`attack_right_punch`、`attack_kick`、`attack_jump_kick` 的命中帧停顿。
- 如果你希望待机更“忍者化”，可以给 `idle` 增加轻微左右观察和更明显的呼吸起伏。
- 如果你希望移动更轻盈，可以在 `walk` 里减小上下颠簸，同时加一点身体前倾。
